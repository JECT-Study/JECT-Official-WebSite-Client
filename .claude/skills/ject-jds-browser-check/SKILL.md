# JDS 브라우저·접근성·시각 검증

현재 git root·대상 HEAD와 dirty 범위·구현 계약을 확인하고 기존 `ject-jds-accessibility` 및 해당 reference를 읽는다. [실행 행렬](references/verification-matrix.md)에서 해당하는 경로를 선택한다. 읽기 전용 검증에서 제품 소스·VRT baseline·의존성·CI를 변경하지 않는다.

## 준비

- 현재 JDS Storybook 설정, 스크립트, 해당 스토리와 실제 테스트 실행 경로를 확인한다. apps/web의 애드온을 JDS에 설정된 것으로 보지 않는다.
- 이미 실행 중인 대상 서버가 있으면 재사용한다. 필요하면 메인이 현재 manifest의 npm Storybook 명령을 실행하고 세션을 관리한다. 검증 담당이 다른 프로세스를 종료하지 않는다.
- 사용 가능한 브라우저/자동 검사/보조 기술 도구를 먼저 확인한다. 실제로 제공되는 API·스냅샷에서 locator를 정하고 도구 문서를 따른다. Playwright·axe·스크린 리더가 있다고 추정하지 않는다.
- 새 테스트 러너·애드온·설정·의존성이 필요하면 기존 도구로 가능한 범위를 마치고 필요한 도입을 별도로 제시한다. 사용자 승인 없이 설치하지 않는다.

## 실행

1. 대상 스토리와 실제 rendered DOM을 연다. 이름·설명·role·상태·ref 대상과 인터랙션 가능한 범위를 확인한다.
2. 계약의 진입 → 조작 → 값/화면 변화 → 닫힘/제출/초기화 흐름을 실제로 실행한다. 외부 props를 바꾸는 스토리를 사용해 초기값만으로 끝내지 않는다.
3. 키보드/포인터로 같은 목적을 달성하는지 확인한다. 열린 Portal에서 disabled/readOnly 전환·Escape·복귀 포커스 등 관련 위험 조합을 확인한다.
4. 관련 W3C 성공 기준을 기준 번호·수준과 함께 점검한다. 정적 DOM, 실제 브라우저 조작·측정, 스크린 리더 낭독 결과를 분리한다.
5. 실제 테마·화면 크기·콘텐츠 조건에서 Figma와 비교한다. 로딩·폰트·애니메이션 안정화 조건을 기록하고 필요 시 스크린샷을 남긴다.
6. 준비된 play assertion/자동 접근성/VRT를 실행한 경우 그 실행 결과와 미포함 범위를 별도로 기록한다. 로그에 assertion 통과가 없으면 실행했다고 쓰지 않는다.

## 시각 회귀

현재 VRT의 태그·viewport·포털 캡처 범위와 play 완료 대기 방식을 source에서 확인한다. 필요하면 기존 `npm run vrt --workspace=@jects/vrt`를 사용한다. Docker가 없으면 미실행이다. baseline 생성·승인은 비교 통과가 아니다.

반응형 변경에는 세 구간의 대표 너비와 767/768, 1199/1200 경계 중 영향받는 경우를 확인한다. 모든 컴포넌트의 모든 조합을 무조건 캡처하지 않는다. 테마/상태/화면 조합의 선택 근거와 누락을 기록한다. Portal은 component root 외부도 확인한다.

## 반환

대상·브라우저/보조 기술 조합·상태·테마·입력 방식·기대/실제·재현 단계·관련 코드·WCAG/APG·증거·판정을 남긴다. fail/skip/미실행을 통과와 구분한다. 관련 기준에서 문제를 찾지 못한 결과와 전체 제품 준수 선언은 다르다.

디자인 의도가 모호하면 임의로 기대값을 정하지 않고 figma-handoff 질문 절차로 연결한다. 가능한 나머지 검증은 계속한다. 음성/스크린 리더를 실행하지 않았다면 실제 낭독을 인용하지 않는다.

## 테스트 시나리오

- 정상: 열린 DateField의 disabled 전환 → 직접 입력·달력 선택 모두 계약을 지키는지 확인.
- 시각: 다크 테마에서 긴 오류 문구 → 의미 있는 메시지·대비·reflow·focus clipping 확인.
- 오류: VRT만 성공하고 키보드 실행 도구 없음 → 시각 비교 결과와 키보드 미검증을 분리.

검사 적용 여부는 [검증 선택](../ject-jds-workflow/references/quality-gates.md)을 따른다. 미검증과 적용 제외를 구분하며 필요한 검사에 도구가 없으면 통과로 보고하지 않는다.

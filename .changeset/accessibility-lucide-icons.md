**Icon — Accessibility 그룹 Lucide 마이그레이션**

Accessibility 그룹 아이콘의 SVG와 공개 `IconName`을 Lucide 기준으로 변경합니다.

| 기존 이름                              | 신규 이름              |
| -------------------------------------- | ---------------------- |
| `question-line`                        | `circle-question-mark` |
| `sun-line`                             | `sun`                  |
| `information-line`, `information-fill` | `info`                 |
| `moon-line`                            | `moon`                 |
| `eye-line`                             | `eye`                  |
| `eye-off-line`                         | `eye-off`              |

`zoom-in`, `zoom-out` 아이콘을 새로 추가합니다. 기존 이름은 더 이상 export하지 않으므로 사용하는 코드는 신규 이름으로 변경해야 합니다.

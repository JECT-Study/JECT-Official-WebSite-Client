# 서버 컴포넌트에서 사용하기

JDS의 기본 진입점(`@jects/jds`)과 `@jects/jds/hooks`는 `"use client"` 경계입니다. 서버 컴포넌트에서 가져온 값은 클라이언트 참조가 되기 때문에, `TextField.Input`처럼 점으로 파트에 접근할 수 없습니다.

## 파트는 개별 이름으로 가져옵니다

서버 컴포넌트에서는 루트 이름과 파트 이름을 이은 개별 export를 사용합니다. 점 표기와 같은 컴포넌트입니다.

- `TextField.Input` → `TextFieldInput`
- `Accordion.Root` → `AccordionRoot`
- `DropdownMenu.Category` → `DropdownMenuCategory`
- `Card.Preset.Plate.Link` → `CardPlateLink`

```tsx
// app/page.tsx: 서버 컴포넌트
import { TextField, TextFieldHelper, TextFieldInput, TextFieldLabel } from "@jects/jds";

export default function Page() {
  return (
    <TextField required>
      <TextFieldLabel>이름</TextFieldLabel>
      <TextFieldInput name='name' defaultValue='' />
      <TextFieldHelper>다른 사람에게 표시할 이름을 입력해 주세요.</TextFieldHelper>
    </TextField>
  );
}
```

파트는 루트가 제공하는 Context를 쓰므로 루트 안에 두어야 합니다.

서버 컴포넌트에서 점 표기를 쓰면 Next.js 16에서는 다음 에러가 발생합니다.

```text
Error: Element type is invalid: expected a string (for built-in components) or a class/function (for composite components) but got: undefined.
```

## 서버 컴포넌트에서 쓸 수 없는 것

- 함수 prop: `onClick`, `onChange`, 렌더 콜백처럼 함수를 넘기는 조합은 소비처의 `"use client"` 파일에서 작성합니다. `onClick`이 필수인 `CardPlateButton`, `CardPostButton`도 여기에 해당합니다.
- `toastController`, `snackbarController`: 클라이언트 코드에서 호출합니다.
- `formatFileSize`: 서버에서 호출하려면 `@jects/jds/utils`에서 가져옵니다. 기본 진입점의 것은 클라이언트 참조라 서버에서 호출할 수 없습니다.

클라이언트 파일에서는 기존 점 표기를 그대로 사용해도 됩니다.

```tsx
"use client";

import { useState } from "react";
import { TextField } from "@jects/jds";

export function NameField() {
  const [name, setName] = useState("");

  return (
    <TextField>
      <TextField.Label>이름</TextField.Label>
      <TextField.Input value={name} onChange={event => setName(event.target.value)} />
    </TextField>
  );
}
```
